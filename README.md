# Сайт-приглашение · Евгения и Кирилл

## Структура

```
wedding/
├── index.html              ← основной файл
├── photo-1.jpg             ← фото пары 1
├── photo-2.jpg             ← фото пары 2
├── fonts/
│   └── Corinthia.ttf       ← кастомный шрифт для имён
└── audio/
    └── wedding-music.mp3   ← фоновая музыка (нужно положить)
```

**ВАЖНО:** при заливке на хостинг — заливай ВСЮ папку целиком, со всеми вложенными.

---

## Шаг 1. Создать Telegram-бота (5 минут)

1. Telegram → @BotFather → `/newbot`
2. Имя бота: например `Свадьба Евгении и Кирилла`
3. Username: что-то вида `evgeniya_kirill_wedding_bot`
4. BotFather пришлёт **токен** вида `7891234567:AAH...`
5. **Найти бота в поиске и написать ему любое сообщение** (`/start`)
6. Открыть в браузере (вставить токен):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
7. Найти `"chat":{"id":123456789` — это **chat_id**

## Шаг 2. Вставить токен в сайт

Открыть `index.html`, найти блок `CONFIG`:
```js
telegramBotToken: 'PASTE_BOT_TOKEN_HERE',  // ← токен от BotFather
telegramChatId: 'PASTE_CHAT_ID_HERE',      // ← chat_id
```

## Шаг 3. Добавить музыку

Положить mp3 файл в `audio/` и назвать **`wedding-music.mp3`** (точно так).

**Где взять трек:**
- Свой любимый трек → конвертировать в mp3
- YouTube → mp3: `cobalt.tools` или `y2mate.com`
- Royalty-free свадебная музыка: `pixabay.com/music`, `freepd.com`, `bensound.com`

**Рекомендации:**
- Длина: 2-5 минут (играет на повтор)
- Размер файла: до 5 МБ (иначе долго грузится)
- Громкость нормальная (плеер играет на 40%)

Если файла нет — кнопка плеера просто не появится, остальное работает.

## Шаг 4. Залить на хостинг (Netlify Drop, 2 минуты)

1. Открыть https://app.netlify.com/drop
2. Перетащить **всю папку `wedding/`** (со всеми подпапками)
3. Получить ссылку вида `https://random-name.netlify.app`

## Шаг 5. Проверка

1. Открыть ссылку
2. Кликнуть на восковую печать «открыть» → клапан конверта откидывается, появляется текст внутри, музыка играет
3. Заполнить тестовую анкету → Евгении в Telegram должно прийти уведомление
4. Нажать «Добавить в календарь» → скачается .ics с напоминаниями за 1 и 2 дня

## Шаг 6. Рассылка гостям

Кидать ссылку в WhatsApp/Telegram/Max. Превью с фото подтянется автоматически.

## Что менять под себя

В `index.html`, блок `CONFIG`:
- `weddingDate` — дата и время
- `location` — адрес
- `description` — текст для календаря

В секции «План дня» — тайминг

В блоке `:root` (CSS) — палитра цветов

## Известные ограничения

- **Telegram bot token виден в коде** — для свадьбы ок, для бизнеса нужен серверный proxy
- **Музыка не запустится без клика** — это политика браузеров. На клик «открыть» запустится сразу
- **Pinterest** в дресс-коде ведёт на поиск, лучше заменить на конкретный борд
- **Polaroid-плейсхолдеры** ждут реальных фото места и блока «Мы выросли»
